# Harbor Homes

Sitio de alquiler mensual de casas en Estados Unidos. Está en español e inglés, con búsqueda al estilo de un portal inmobiliario y un panel privado para editar casas, precios, fotos y el texto de la portada.

## Desarrollo

```bash
npm install
npm run dev
```

Abre el sitio en `http://localhost:8080`. El panel del administrador está en `/panel`.
